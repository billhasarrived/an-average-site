Hardware Changes

I have acquired a Nvidia Geforce GTX 980 TI which I have put into my main system, It works really well for most of the games I play, which is expected as they all either can run on a potato, or they are made before 2018. Fallout 4 is especially a standout as this was the "High End" card when Fallout 4 released in 2015, which means it is practically smooth as butter, even modded. Unfortunately for me, Nvidia has decided to wind down support for the 900 and 10 series cards by the 580 drivers, which is a pain, and I'll probably switch to linux when that happens.

Recent Endeavors

I have been messing around with Hyper-V a bit, I have found that it is several times more performant than Virtualbox will ever be, mostly due to it being a Kernal Virtual Machine (KVM). I tried and failed to install ReactOS in it, with the realization that ReactOS still has a longstanding bug relating to Hyper-V which prevents booting at all. I then installed Windows 7 which went perfect as usual, and now I'm in the process of installing Gentoo.

Linux & Open Source Tidbits

Microsoft Open-Sourced an edit.com Rust Reimplementation.

Github Page

As I have been looking for an edit.com clone for ages, it's nice to see a reimplementation by Microsoft themselves. You should be able to install it on Arch Linux and Derivatives through the ms-edit package and on Freebsd through the microsoft-edit port.


ReactOS Alpha 0.4.15 has released.

ReactOS News Post

It has been a while since the last one, and it looks like they made some nice progress.
